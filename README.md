# AMDCD Frontend

## Nombre completo

Arquitectura Multiagente para el Descubrimiento Causal Distribuido: Filtrado de Relaciones Espurias y Negociación Dinámica de Restricciones.

## Descripción breve

Frontend del centro de comando analítico para visualizar métricas, grafos causales, auditoría XAI y estado del ecosistema multiagente.

## Stack planificado

- React
- TypeScript
- Vite
- React Router
- Tailwind CSS
- shadcn/ui
- React Flow
- Apache ECharts
- Zustand
- TanStack Query
